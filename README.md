# MyFirst2DGame
# -----Dragon Clicker-----

**Dragon Clicker** — простой и увлекательный 2D-кликер, разработанный на движке Unity с использованием C#. 

## 📌 О проекте
Это мой первый завершенный игровой проект, доведенный до полноценного рабочего билда. Игра сочетает в себе механику кликов, систему прокачки персонажа, внутриигровой магазин и систему достижений.

## 🎮 Основные механики:
* **Интерактивный кликер:** Клик по центральному объекту приносит игровую валюту.
* **Прокачка персонажа:** Повышение уровней и силы дракона по мере накопления опыта.
* **Магазин улучшений:** Покупка апгрейдов для увеличения эффективности кликов.
* **Система бонусов:** Покупка авто-клика и дополнительных усилений.
* **Достижения:** Отслеживание прогресса игрока по выполнению ключевых целей (заработок определенной суммы, клики и т.д.).

## 🛠 Технологии:
* **Движок:** Unity (2D)
* **Язык программирования:** C#
* **Система контроля версий:** Git / GitHub
